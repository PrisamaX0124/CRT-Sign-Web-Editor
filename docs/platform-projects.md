# 导向与站台本地多项目管理

导向和站台页顶部的文件夹按钮可打开「我的项目」。点击项目名称打开工程。可以搜索、排序和切换卡片或列表视图。改名、复制、备份和删除收在项目右上角的菜单里。底部「备份与恢复」可下载当前工程和旧存档，也可重试保存。

当前工程名称显示在预览标题栏，例如「重庆1号线 / 全线吊板」。导向新项目从一行空白的标识牌开始，站台新项目使用默认站台工程。删除需要确认。删除最后一份项目后，会创建一份默认工程。

项目与预设分别保存。项目用来继续编辑一份工程；预设仍用于重复使用常用内容。导向仍可将一行内容存为预设，站台仍保存整份预设。换乘继续用原有自动保存、预设和 JSON 导入导出。

## 保存与迁移

- IndexedDB 数据库分别为 `public-guidance-projects` 和 `public-platform-projects`，当前数据库版本均为 1。`projects` 保存独立项目标识、名称、创建时间、修改时间、写入版本、列表资料和完整工程 JSON。`settings` 单独保存当前项目标识及旧存档迁移记录。
- 导向沿用 `SignState.serializeSign`、`SignState.deserializeSign`。站台沿用 `PlatformState.serialize`、`PlatformState.deserialize`。导入会先校验工程，站台还会检查底纹图片。校验后以文件名创建一个新项目，原项目继续保留。
- 升级时读取旧自动存档。导向将 `public-sign-autosave` 保存为「原有导向项目」，站台将 `public-platform-sign-project-v1` 保存为「原有站台项目」。工程与迁移记录在同一个事务中写入，事务全部完成才算成功。重复刷新或两个窗口同时首次升级，都只产生一份迁移项目。
- 旧的 localStorage 原文始终保留，不自动删除。「我的项目」中有备份旧版自动存档的入口。迁移失败或中断不会留下成功标记；恢复存储后可以重试。损坏的项目保留原文，项目卡片提供 JSON 备份。
- 修改后等待 500 毫秒再自动保存。保存与切换依次执行；切换前会保存最后的编辑内容，保存失败会停留在当前工程。名称、列表资料和工程内容一起写入，事务完成后才显示「已保存」。
- 每次写入检查项目的写入版本，检查和写入在同一个事务中完成。其他窗口修改或删除同一项目后，本页停止保存，并提供备份、重新打开和另存副本。支持时通过 `BroadcastChannel` 即时通知；页面重新获得焦点、回到前台及写入之前也会检查。
- 切换通过 `App.update` 应用工程，并清空选区、撤销重做、连续编辑记录、拖动和剪切位置。导向还会退出预设预览，切换前发起的剪贴板读取不能修改新项目。站台批量预览和导出沿用打开时的工程副本。

## 测试审查清单

| 用例 | 应有结果 |
| --- | --- |
| 旧导向工程带行背景和灰框，旧站台工程带站点、换乘、底纹和位置调整 | 迁移后工程完整，旧原文不变，刷新不重复迁移 |
| 两个窗口同时首次迁移；迁移中途事务中断 | 只写一份；中断后工程与迁移记录一起回退，重试成功 |
| 新建、改名、搜索、按时间排序、复制、取消删除、确认删除 | 列表与当前项目一致，删除前确认；最后一份删除后有默认工程 |
| 连续编辑后快速切换多次 | 每份项目保存自己的最后内容，旧写入不能覆盖新编辑 |
| 复制工程后修改站点、线路和排版 | 原项目不变，完整工程资料保留，项目标识独立 |
| 空间不足、写入被拒绝、存储不可用、损坏项目 | 明确提示，保存失败禁止切换，JSON 备份包含本页最新内容 |
| 删除最后一份工程时事务中断 | 原工程不被删除，也不留下多余默认工程 |
| 切换前有选区、撤销记录、拖动或等待中的粘贴 | 临时状态不跨项目，较晚返回的粘贴结果不改动新工程 |
| 导向和站台同时编辑，打开换乘编辑器 | 两种工程及当前项目各自保存，换乘按原方式保存与导入导出 |
| 两个窗口修改同一项目，或各自编辑不同项目 | 检测冲突并禁止覆盖；另存副本保留本页内容。不同项目可分别编辑 |
| 导入正常与损坏 JSON、损坏底纹 | 正常文件另建项目；错误文件不改当前工程 |
| 批量生成、逐站反向、双列交换、PNG／SVG／ZIP 导出 | 原有行为保持一致；切换项目不改变已打开批量任务的工程 |
| 预设、图床上传、深色模式、Esc、焦点与减少动态效果 | 原有预设及上传正常；对话框可用键盘操作，系统减少动态效果时不播放进入动画 |

单元测试见 `test/platform-projects.test.mjs` 和 `test/project-files.test.mjs`；使用真实 IndexedDB 的浏览器用例见 `test/guidance-projects.html` 和 `test/platform-projects.html`。批量生成和原有站台交互继续由 `test/platform-batch.html`、`platform-test.html` 等页面回归检查。图床回归使用模拟服务，不会上传测试图片到外部服务。

## 使用范围

项目保存在当前浏览器、当前网站地址下。清除网站数据会删除项目，跨设备需要导出和导入 JSON。本阶段没有账号、云同步或版本历史。

页面进入后台时会尽快保存；仍有未保存修改或冲突时，离开页面会请求确认。浏览器被强行关闭、进程被终止或设备断电时，最后一笔尚未完成的写入不能保证保留。长期保存请下载 JSON 备份。站台 JSON 导入仍有 2 MB 上限。导向继续沿用原有的导入规则。
