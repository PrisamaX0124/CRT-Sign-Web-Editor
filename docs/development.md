# 开发指南

`index.html` 打开导向标识编辑器。点页眉左侧的编辑器名称可切换编辑器，页眉中间的按钮用于调整当前标识牌的版式。也可以直接打开 `index.html?editor=transfer` 编辑换乘标识，或打开 `platform.html` 编辑站台标识。页面、样式、脚本和字体都在仓库内，由浏览器直接加载。

三个编辑器共用桌面三栏，页面最小宽度为 1100 像素。窗口更窄时可以横向滚动，手机浏览器会把同一页面缩放到屏幕宽度。

## 编辑、排版与保存

- 导向标识的状态、排版和属性面板分别在 `js/state.js`、`js/render.js` 和 `js/panel.js`。站台标识的状态与排版在 `js/platform/`，交互入口在 `js/platform/main.js`。
- 项目通过 `App.update` 提交修改，供撤销、重做和自动保存使用。站点以固定标识查找，调整站序后仍能找到原本站。导入项目时由状态模块校验数据并处理旧格式。
- 三个编辑器都可从右栏的「项目」标签导入和导出项目 JSON。换乘项目文件同时保留版式 A 和版式 B，导入整份项目算一次修改。更换设备时，可在原设备导出项目，再在新设备打开对应的编辑器导入。
- 三个编辑器的右栏根据当前选区显示「编辑」「外观」「项目」。内容、常用颜色和排版在「编辑」，底纹、行背景和灰框等细节在「外观」。连续选择同类对象时保留当前标签。只有中间属性区滚动，底部固定提供 PNG 下载（1×／2×／4×）、SVG 下载和原尺寸图床上传。
- 预览、选框和导出共用排版结果。字体和颜色选择器由两个编辑器共用。导出时按绘制结果选取要内嵌的字体。
- 三个预览区各自记录视图位置和缩放比例。标题栏的固定档位和「适应画布」平滑过渡。按住 Shift 滚动时，画布立刻以指针为中心缩放，菜单显示当前比例。锁打开时，可以用左键拖动画布空白处，也可以按住滚轮拖动。锁合上时，画布位置和比例固定，仍可编辑元素。底部保留保存状态和「快捷键」说明。
- 导向标识默认开启「自由移动」。元素可左右拖动，也可整块吸附到另一行。拖动时同一行的其他元素会让位。「吸附对齐」默认开启，多选一起对齐。关闭「自由移动」可按排列顺序拖动，并使用浮动栏的向左、向右移动按钮。
- 拖动整行时，其他行会让出插入位置。从左栏拖入元素时，牌面预演加入该元素后的排版。松手才提交修改，取消整行拖动时各行会归位。
- 已摆好的元素靠近左缘、中央或右缘时，会按对应位置排版。文字变长时，同一行会留出后续元素的空间。如果一行确实放不下，会按原比例缩小该行的元素。选中已调整位置的元素时，可用「恢复排版」回到原位置。
- 站台标识通过左侧站点列表或站点管理按钮调整站序。拖动站点时，相邻卡片会让出落位空间，松手才调整站序。切换本站后，牌面短暂高亮新本站。牌面用于点选元素，元素位置通过属性栏或浮动栏微调。
- 站台标识的「导出」区提供「批量生成」。选好版式、站点和文件格式后，可以翻页预览、查看大图和取消勾选，再将所选标识牌打包下载。吊板和纵向单列可选择一种行车方向或同时生成两种。选一种时可以在预览中逐站反向。纵向单列沿用整牌设置的左右版式，双列每站生成一张并沿用当前列序，可逐站交换左右列。打包在浏览器内完成，使用打开对话框时的项目状态和预览中选定的方向。
- 站台标识的「编辑」签同时提供线路、行车方向和排版。选中站点时同页编辑站名、换乘和位置。左侧列表始终高亮当前本站的定位图标，悬停或用键盘聚焦其他站点时可设为本站。浮动栏和属性栏也提供这一操作。
- 站点可分别添加数字线路和文字线路，最多六条，每条都能单独编辑、选色和删除。「批量填写」接受原有的逗号分隔格式。换乘列表只在所选站点或换乘类型、条数变化时重建。普通改名和改色继续使用原控件。
- 三个编辑器共用动画时长和缓动曲线。右侧标签、选区属性、预设和牌面版式切换时播放过渡。系统开启「减少动态效果」时直接切换。
- 换乘标识可在「项目」中将两个版式一起存为浏览器预设，从左栏「预设」载入。载入整个预设可一步撤销。
- 换乘标识的版式 A 和版式 B 分别保存。版式 A 的线路共用箭头和文字。版式 B 有单线路、「1 + 1」、「1 + 2」和「2 + 1」四种样式。每组的箭头和文字都在本组最后一条色带下方。点选箭头或文字，可以调整本组对齐，也可选择箭头放在文字哪一侧。各样式分别保存上下两组的设置。整组右对齐时，每列双语文字以墨区右沿对齐。点选牌面色带可编辑该条线路的名字、颜色和底纹，点选箭头可在导向标识共用的方向图标中选择。换乘标识与站台标识共用底纹控件和绘制规则。
- 换乘标识中，输入数字或「6号线」这样的名称时，按数字线路排版。文字线路可另填英文名称，也可以只填英文名称。打开「放大线路名」后，中文名称末尾已有的「线」使用小字，与英文名称排在一列。数字线路和文字线路可放在同一组。

## 站台本地多项目

站台页通过顶部「我的项目」管理多份工程，JSON 导入默认创建新项目。导向与换乘编辑器沿用原有保存方式。项目资料、工程 JSON、旧存档迁移记录和当前项目标识保存在 IndexedDB；预设继续单独保存。存储事务在 `js/platform/project-store.js`，保存与切换在 `js/platform/projects.js`，对话框在 `js/platform/project-dialog.js`。[数据迁移、异常处理和测试审查清单](platform-projects.md)

## 测试

运行 `node --test test/*.test.mjs` 检查状态、排版、导入导出、撤销、颜色和字体。可在命令中加入 `--experimental-test-coverage --test-coverage-exclude="vendor/**"` 查看单元测试覆盖率。

运行 `python -m http.server 8000` 启动本地服务，再在浏览器打开以下页面。每个页面的标题会显示测试结果。

请用测试地址或独立的浏览器环境运行浏览器用例，测试会向同源的 localStorage 和 IndexedDB 写入数据。
